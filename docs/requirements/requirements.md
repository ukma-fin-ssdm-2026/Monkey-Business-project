## Нефункціональні вимоги (NFR)
### Продуктивність (Performance efficiency)
- PERF-1: Час повного завантаження Канбан-дошки зі 100 картками вакансій становить <= 1 с при одночасній роботі 20 активних користувачів.
- PERF-2: Час відповіді сервера на CRUD-операції становить ≤ 200 мс (95%).

### Надійність (Reliability)
- REL-1: Час безвідмовної роботи системи становить >= 99% протягом усього періоду тестової експлуатації.
- REL-2: При перебоях з мережею операцій зі зміни стану картки зберігаються та успішно синхронізуються із сервером після відновлення зв'язку.

### Безпека (Security)
- SEC-1: Паролі користувачів зберігаються в базі даних у хешованому вигляді.
- SEC-2: Тривалість сесії становить 24 години, після чого користувач має пройти повторну авторизацію.
- SEC-3: Ментор не має прав на виконання методів редагування та видалення для сутностей карток кандидата.

### Зручність використання (Usability)
- USAB-1: Інтерфейс дошки коректно відображається без горизонтального скролу із шириною екрана >= 360px (розмір екрану телефона).
- USAB-2: Час, необхідний новому кандидату для створення першої картки вакансії становить < 60 секунд.
