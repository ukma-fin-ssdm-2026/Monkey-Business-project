# User stories

## US-1: Як адміністратор, я хочу мати можливість отримувати звернення підтримки інших користувачів, щоб реагувати на них, та приймати дії для покращення сервісу.

Критерії прийняття:
- редактор звернень у підтримку в користувацькому інтерфейсі
- окрема сторінка звернень для адміністратора
- різні статуси звернень (відкрите, закрите, та інш.)
- зворотній зв'язок з автором звернення

## US-2: Як ментор, я хочу отримувати email-сповіщення про нові заявки на менторство, щоб вчасно розглядати їх і давати відповідь кандидатам.

Критерії прийняття:
- можливість надсилання email сповіщень на бажану пошту через користувацький інтерфейс
- посилання на реєстарцію користувача та/або прив'язку до дошки кандидата через email
