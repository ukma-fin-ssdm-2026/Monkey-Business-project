## Рефакторинг перевірки доступу до картки (Лаб 8)

База порівняння: `pre-refactor`, коміт `0699683`. Робоча гілка:
`codex/lab08-card-access-refactor`.

- **Запах:** Duplicated Code — однакова функція `_require_card` у
  `card_links.py` і `card_notes.py`; ці файли зазначені вище серед джерел дублювання.
- **Техніка:** Extract Function — спільна `require_card` у
  `src/api/routers/card_access.py` замість двох копій.
- **Структурна зміна:** сім викликів у двох роутерах використовують одну реалізацію.
  Правила доступу тепер можна підтримувати в одному місці.
- **Незмінна поведінка:** спочатку перевіряється існування дошки, потім права
  користувача, потім належність картки до дошки. Збережено повідомлення помилок,
  HTTP-коди, параметр `write` та CRUD посилань і нотаток.
- **Доказ:** `tests/test_card_links.py`, `tests/test_card_notes.py` та
  `tests/test_card_access_regression.py`. Останній файл перевіряє точні повідомлення
  для відсутньої дошки/картки, чужої картки та заборону читання картки до перевірки прав.
  Усі 30 сценаріїв пройшли до і після рефакторингу.
