### Погоджене пояснення автора

SQLite використано для швидких локальних інтеграційних перевірок взаємодії API та SQLAlchemy без запуску окремого сервера БД. Це спрощує налаштування тестів. Перевірки збереження даних у новій сесії PostgreSQL винесено в окремі тести, оскільки SQLite не відтворює особливості PostgreSQL.

У TP-12 вимірюється час користувацької операції до появи посилання в інтерфейсі. Поточний відлік починається перед заповненням поля й включає додатковий час автоматизації. Для відповідності тест-плану відлік потрібно починати після заповнення поля, окремо фіксувати завершення HTTP-запиту та оновлення UI, а збереження підтверджувати повторним GET.
